## What I did

Prepared Mergington High School's extracurricular activities repository so more teachers can collaborate safely.

| Step | Topic | What it covers |
|------|-------|----------------|
| 1 | Protect your code | Rulesets and configuration that restrict changes to `main` |
| 2 | Prepare to collaborate | Contributor guidance and code ownership (`CODEOWNERS`) |
| 3 | Foster healthy growth | Ground rules for a healthy collaboration environment |
| 4 | Prepare for the inevitable | A process for managing security updates |
| 5 | Merge | Merge the changes through the protected workflow |
